# M1 — Fundação: Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Projeto rodando localmente com um comando, CI verde e fluxo de cadastro → verificação → login → perfil funcionando de ponta a ponta.

**Architecture:** Monorepo com `api/` (Laravel 13, API JSON stateful via Sanctum SPA + Fortify headless) e `web/` (Nuxt 4 SPA). Em dev e produção um Nginx único serve tudo na mesma origem: `/api/*` e `/sanctum/*` vão para o PHP-FPM, o resto para a SPA (dev server em dev, arquivos estáticos em produção). Mesma origem elimina CORS e simplifica cookies do Sanctum (D21).

**Tech Stack:** PHP 8.4 (Docker), Laravel 13, Fortify 1.41, Sanctum 4, spatie/laravel-activitylog 5, Pest 3/4, Larastan 3, Pint · Node 22, pnpm 10, Nuxt 4.6, Nuxt UI 4, Vitest, Playwright 1.64 · PostgreSQL 16, Mailpit · GitHub Actions.

**Spec:** [financeiro-pro-spec-v2.md](../../../financeiro-pro-spec-v2.md) · **Backlog:** [financeiro-pro-backlog-mvp.md](../../../financeiro-pro-backlog-mvp.md) (US-001 a US-006, US-101 a US-105, US-107)
